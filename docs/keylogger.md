# Keylogger 在 Linux 上的实现与工具推荐

在 Linux（特别是您使用的 **Fedora**）上，如果您想记录或回放键盘的原始输入（包括删改、英文模式下的按键等），通常需要利用内核层、显示服务器层（X11/Wayland）或输入驱动层的工具。

由于 Fedora 默认使用 **Wayland** 显示服务器，传统的 `xev` 可能无法捕获所有窗口的输入。以下是针对不同层级的详细工具介绍：

## 1. 基础诊断工具（底层查看）

这些工具通常用于调试，能让您实时看到每一个按键动作。

*   **`showkey` (控制台层)**
    *   **原理：** 直接从标准输入或内核读取扫描码。
    *   **特点：** 它主要在虚拟终端（TTY，按 `Ctrl+Alt+F3` 进入的那种环境）中使用。在图形界面（GNOME/KDE）的终端模拟器中往往无法正常工作。
    *   **命令：** `sudo showkey -a` (查看 ASCII 码) 或 `sudo showkey -s` (查看扫描码)。

*   **`xev` (X11 窗口层)**
    *   **原理：** 监控 X11 窗口系统发送给窗口的所有事件。
    *   **在 Fedora 上的局限：** 如果您使用的是 Wayland，`xev` 只能捕获运行在 XWayland 下的旧版应用的输入。
    *   **用法：** 终端输入 `xev`，会弹出一个空白小窗口，只要鼠标悬停在该窗口上并按键，终端就会打印出极其详尽的按键事件（按下、抬起、按键名、Keycode）。

*   **`libinput debug-events` (现代 Linux/Wayland 推荐)**
    *   **原理：** 直接监听 `/dev/input/` 下的设备事件，不依赖显示服务器。
    *   **特点：** 在 Fedora/Wayland 上这是**最通用**的方法。
    *   **命令：** `sudo libinput debug-events`
    *   **效果：** 它能实时滚动显示系统中所有输入设备的动作。你会看到类似 `KEY_BACKSPACE (14) pressed` 这样的记录。

---

## 2. 高级“包装”工具（实现记录与回放）

如果您需要将这些按键“保存下来”或“美观地展示”，可以使用以下更高层级的工具：

## A. 后台记录型：`logkeys`
如果您想实现“完整记录删改过程”，这是一个典型的“按键记录器（Keylogger）”。
*   **功能：** 作为一个守护进程运行在后台，将所有的按键动作（包括退格、组合键）记录到一个日志文件中。
*   **安装：** 在 Fedora 上可能需要通过源码编译或寻找第三方仓库。
*   **用法示例：** `sudo logkeys --start --output /home/user/keystrokes.log`
*   **注意：** 它记录的是原始按键。如果按了 5 次退格，日志里会清晰地显示 5 个退格符。

## B. 实时展示型：`screenkey`
这通常用于做视频演示（Screencast），也就是您在某些教程中看到的“屏幕下方跳出按键名”的效果。
*   **功能：** 实时在屏幕上悬浮显示您按下的所有键。
*   **在 Fedora 上的状态：** 支持 X11 和部分 Wayland 环境。
*   **特点：** 它能非常直观地显示出您在输入过程中是如何修改内容的（比如显示：`h` `e` `l` `l` `[Backspace]` `o`）。

## C. Wayland 专用展示：`wshowkeys`
如果您在 Fedora 上使用的是 Sway 或其他基于 wlroots 的合成器，这是最佳选择。
*   **原理：** 专门为 Wayland 设计的按键显示工具。
*   **特点：** 相比 `screenkey`，它对 Wayland 的原生支持更好，能够跨窗口捕获按键并展示。

---

## 3. 应用层解决方案（防止内容丢失）

如果您记录按键的目的是为了防止文档写一半崩溃或找回误删的内容，与其依赖输入法，不如依赖编辑器：

*   **Vim 的 `undotree`：** 它可以记录整个文档的编辑路径（包括分支），即使你删了一段话又写了新的，通过 `undotree` 也能找回“平行时空”里的内容。
*   **VS Code 的 `Local History`：** 自动在本地保存文件每隔几分钟的版本，可以非常方便地对比和找回删改记录。

## 总结建议

1.  **想实时看按键细节：** 使用 `sudo libinput debug-events`。
2.  **想后台静默记录所有操作：** 搜索并配置 `logkeys`。
3.  **想在录屏时展示输入过程：** 安装 `screenkey`。
4.  **想找回文档删改历史：** 养成使用带有“本地历史记录”功能的编辑器的习惯，或使用 Git。

**⚠️ 安全提示：** 请谨慎使用此类记录工具。键盘记录日志包含您的**密码、私钥、聊天记录**等敏感信息。如果您配置了自动记录，请务必确保日志文件的权限仅限您自己读取，并定期清理。
