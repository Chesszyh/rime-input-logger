# 下一轮功能开发矩阵

## 本轮目标

记录输入过程并提供可解释的行为统计，改善连续片段阅读。**不还原应用最终正文**，不做撤销重放、文档差异或全文编辑轨迹重建。英文观察与确认上屏分别计数，不混作同一份正文。

优先级：P0 为采集闭环，P1 为下一轮主要功能，P2 为依赖新字段的后续扩展。“有事件”不代表已经有可靠指标或页面。

## 当前基线

确认上屏已有每日次数、字符数和词云；连续片段已有阅读视图。组合开始/结束、取消、焦点边界、输入法切换与编辑边界已有采集代码，尚未形成完整统计面板。

用户实际使用仍看不到英文。本次检查中，实际行为日志没有英文观察和 Rime 模式切换事件，而存在 Fcitx5 输入法切换事件；接口解析无错误。**英文采集仍是未解决问题**。之前隔离 Rime 测试通过，仅证明通知处理有效，没有验证用户的 Shift 切换路径。

## 功能矩阵

| 优先级 | 功能 | 当前基础与可行性 | 下一轮开发内容 | 统计口径与验收 |
|---|---|---|---|---|
| P0 | 英文观察真正可见 | 当前实现未覆盖实际场景，必须先修 | 在实际应用复现 Shift 切换，区分 Rime 内部英文模式与 Fcitx5 键盘输入法；必要时在 Fcitx5 层观察放行按键，避免两层重复记录 | 同一段合成中英文经过实际输入路径，在日志、接口、页面三处对应；快捷键与按键释放不作为英文字符；不改变应用收到的输入 |
| P0 | 采集状态与数据来源 | 页面仅有总量，缺少链路状态 | 显示各来源最近事件时间、有效事件数、解析错误及覆盖说明；将“服务运行”和“某来源已有数据”分开 | 无英文事件显示“尚未收到”，不能显示为已验证；旧数据缺字段显示不可计算，不显示虚假的 0 |
| P0 | 时间与组合关联 | 秒级时间、会话序号已存在，精确耗时不足 | 补组合 ID、单调时钟毫秒值及采集进程 ID；跨进程不比较单调时间，保留日期用的墙上时间 | 能区分提交、取消与未结束组合；同秒多次输入仍有稳定顺序；进程 CPU 时钟不得用于组合耗时 |
| P1 | 每日输入量与趋势 | 现有确认上屏数据可做 | 日/周/月趋势、中文与英文观察分列、按日期对比 | 上屏数/字符数来自确认记录；英文观察字符单列，能与导出结果对账 |
| P1 | 活跃时段 | 现有时间戳可做 | 小时分布、星期×小时热力图、活跃分钟数 | 有输入事件的分钟才计为活跃分钟；不把两条记录间的整个间隔都算成工作时长 |
| P1 | 连续片段统计 | 已有分组与边界，可做 | 片段数、字符数分布、中位长度、断开原因；显示片段内上屏与英文观察的构成 | 切换分组阈值后同步重算；不跨焦点、会话和编辑边界拼接；旧日志注明仅按时间/标点分组 |
| P1 | 词频变化 | 词频与前期对比计算已有，可接真实页面 | 新词、上升/下降词、周/月对比与停用词设置 | 比较等长时间段，过滤规则一致；先只统计确认上屏，英文观察不自动并入 |
| P1 | 组合耗时 | 有起止事件；补时间与组合 ID 后可做 | 提交/取消组合分别统计中位耗时与耗时分布 | 仅计算成功配对且同一采集进程内的组合；未结束、重启中断单列；不解释为用户思考耗时 |
| P1 | 取消比例 | 已有取消原因，可先做粗略版 | 取消次数、提交次数、取消率；补 ID 后提高配对可靠性 | 取消率＝取消结束数÷（提交结束数＋取消结束数）；未结束组合不进分母；不能称为输入错误率 |
| P1 | 中英文切换次数 | 事件种类存在，实际 Rime 模式事件未验证 | 同时记录框架输入法名称和 Rime ascii_mode；分别展示模式切换与输入法切换 | 只统计明确的状态变化；去除初始化与重复通知；不能把焦点切换或所有输入法切换都称为中英文切换 |
| P1 | 退格频率 | 当前 edit_boundary 混合多种键，不能直接算 | 增加键类型、是否处于组合、重复按键标识；区分组合内退格与放行退格 | 展示退格次数/每百次观察按键的退格次数，明确分母；编辑边界数不等于退格数，也不等于删掉的字符数 |
| P1 | 焦点切换 | 已有获得/失去焦点事件，可做 | 焦点进入次数、输入片段跨焦点分布；配对前台输入上下文 | 将 FocusOut/FocusIn 看作一次转换过程；不简单相加为切换次数，也不等同应用切换 |
| P2 | 按应用分布 | Fcitx5 可提供程序名，但当前未落盘 | 采集 currentProgram 和输入上下文标识，关联焦点与上屏/观察事件 | 缺失名称归“未知”；应用不明时不猜测；Wayland 下需用实际应用验证覆盖范围，不收集窗口标题或正文 |
| P2 | 选词方式 | 当前没有足够数据，需补采与验证 | 关联候选选择事件、候选索引与触发操作；区分空格、数字、翻页后选择、鼠标及自动提交 | 键盘与鼠标分别验收；只凭提交前最后一个键不能断言选词方式；无法关联的归“未知” |
| P2 | 编辑操作概览 | 可扩充按键与组合事件，无需正文重建 | 退格/删除/取消/导航/快捷键次数，编辑密集时段 | 展示观察到的操作及其频率；快捷键不证明操作生效，不计算“最终删改了多少正文” |
| 不做 | 最终正文与完整修订轨迹 | 已明确排除 | 不采集或重放应用正文，不实现文档恢复 | 保留输入历史和操作统计即可 |

## 实施顺序与交付

1. **采集闭环**：先修实际英文路径，补来源状态、毫秒计时和组合 ID。使用真实 Fcitx5 → 应用路径测试中文、Shift 英文、返回中文、退格、取消和切换输入框；隔离引擎测试作为补充。
2. **日常统计**：交付输入趋势、活跃时段、片段统计、词频变化；接入可验证的组合耗时、取消率和模式切换统计。
3. **细分行为**：补退格键分类、应用归属和候选选择，再交付相关统计。界面仍保持侧栏分页面，明细放在对应页面内。

采集修复和统计功能分开提交；每次提交包含对应合成样例、口径说明与测试。真实日志不用于公开测试夹具。只在目标应用的实际路径验收通过后，才将英文采集标记为已解决。
